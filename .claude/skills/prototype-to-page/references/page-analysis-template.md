## 10. 文件与职责方案

只列实际需要的文件，不要求把下列可选项全部创建：

```text
src/pages/<Page>/
├── index.tsx             页面组合与 UI 事件
├── index.less            页面样式，按需
├── model.ts              复杂共享业务流程，按需
├── type.ts               页面业务类型与有职责的泛型，按需
├── constants.ts          固定枚举、配置，按需
├── utils/                页面纯计算，按需
└── components/
    └── <Component>/
        ├── index.tsx     组件实现与默认导出
        ├── index.less    组件局部样式，按需
        └── model.ts      按需，先核对注册与状态归属

tests/<page>.test.ts      与运行实现分离的测试，按既定测试工具组织
```

实例隔离逻辑依 `umi-max` 使用不会被扫描的本地 Hook；不创建空 model。接口及协议类型归所属 service，跨页共用内容才提到共享目录，生成文件不手改。
